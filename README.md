樣鞋房雙系統管理帳本 (專業雲端版)

這是一個專為鞋類工廠開發的數位化樣鞋管理系統，將傳統的「紙本流水帳」與現代的「實時庫存管理」深度整合。系統採用 Firebase 作為後端雲端數據庫，支援多裝置即時同步，並針對樣鞋房特有的「先入庫、後借出」流程進行了優化。

🌟 核心管理邏輯 (Core Logic)

本系統與一般簡易帳本不同，我們設計了兩套互相補全的視圖：

1. 樣鞋房在庫現況 (Inventory View) - 「實體在哪裡」

用途：用於盤點目前留在辦公室（架上）的所有樣鞋。

智慧入庫：點擊右上角「新增在庫樣鞋」，僅需填寫型體資訊。此時系統視為「純入庫」，不會產生干擾性的流水紀錄。

快速借出：對著在庫型體「左鍵雙擊」或點擊綠色 + 號，即可直接辦理借出，系統會自動帶入型體資料，僅需補上借用人。

2. 借還流水帳 (Ledger View) - 「歷史發生了什麼事」

用途：記錄每一次的「人貨變動」。

精簡顯示：自動隱藏「純入庫」的行政紀錄，僅顯示有借有還的交易流水。

狀態一致性：已歸還的紀錄會顯示為「已結案」，未歸還則標示為「外借中」。

🚀 重點功能

即時雲端同步：辦公室電腦輸入，現場手機同步顯示最新狀態。

批量歸還簽收：支援選取多個型體一次辦理歸還，大幅提升大袋樣鞋收回時的速度。

智慧篩選系統：包含品牌、部門、人員、季節、型號等全欄位即時下拉篩選。

資料保護與備份：內建 CSV 匯出功能（週報備份用）與 CSV 批次匯入（歷史資料平移用）。

專業版面設計：對齊業界標準，借用部門與借用人採並列排版，介面清爽。

🛠 技術架構與設定

環境參數

前端框架: Tailwind CSS, Lucide Icons

雲端引擎: Firebase (Firestore + Authentication)

API 安全: 已配置網域限制 (shuchia.github.io) 與匿名登入機制

Firebase 權限規則 (Security Rules)

為確保資料安全，請確保您的 Firestore Rules 設定如下：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/shoe-factory-manager-ledger/public/data/{collectionName}/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}


📋 操作指南

收到全新樣鞋：切換至【在庫現況】-> 點擊【新增在庫樣鞋】。

人員前來借樣：在【在庫現況】找到型體 -> 雙擊 -> 填寫【部門/姓名】-> 確認借出。

人員歸還樣鞋：在【流水帳】選取該列（或勾選多列）-> 點擊【批量歸還】-> 簽收結案。

每週備份資料：點擊【匯出報表】，下載 CSV 檔案留存。
